🚨 Force Reload Store

Paksa server reload data dari Supabase ke RAM (_store). Gunakan ini jika data sudah benar di Supabase tapi masih belum muncul di app.

ℹ️ Cara Pakai

1. Cek Data → lihat format data di Supabase untuk user yang login.
2. Jika "Format Supabase" bukan array[N] → klik Repair.
3. Setelah Repair → buka app dan cek Laporan Kegiatan lagi.
4. Jika masih kosong → coba Force Reload lalu buka Laporan lagi.

⚠️ Halaman ini hanya bisa diakses oleh Owner/Admin.
