📋 Urutan Go-Live yang Direkomendasikan

  • 1️⃣
    Pastikan semua master data sudah benar
    Data karyawan, area/radius, grup, kebijakan cuti, hari libur — cek di aplikasi utama
  • 2️⃣
    Export data dari Jibble
    Catat sisa cuti tahunan dan saldo overtime tiap karyawan dari Reports → Time Off di Jibble
  • 3️⃣
    Reset data uji coba
    Buka tab "Reset Data", ketik konfirmasi, klik Reset. Lakukan ini tepat sebelum go-live
  • 4️⃣
    Import saldo dari Jibble
    Buka tab "Import Saldo", isi data per karyawan, klik Import
  • 5️⃣
    Verifikasi saldo
    Buka tab "Cek Saldo", periksa beberapa karyawan memastikan data masuk dengan benar
  • 6️⃣
    🚀 Mulai operasional!
    Aplikasi siap digunakan. Setelah go-live, hapus file admin-golive.html dari server agar URL ini tidak bisa diakses lagi

⚠️ Catatan Penting

  • Halaman ini tidak muncul di menu aplikasi — hanya yang tahu URL-nya yang bisa akses
  • Semua aksi di sini hanya bisa dilakukan oleh Owner
  • Setelah go-live, hapus file admin-golive.html dari folder public/ di server
  • Reset data bersifat permanen — tidak bisa di-undo
  • Import saldo bisa dijalankan ulang jika ada koreksi — nilai akan dijumlahkan, bukan ditimpa
